# Title: HW 1 - Area Calculator
## Description:
In this assignment, the program begins by prompting the user to choose a shape to calculate the area for.
Once the user chooses the shape, the program asks for the lengths needed to make calculations.
Finally, the user can choose to either to make another computation, or exit the program.
